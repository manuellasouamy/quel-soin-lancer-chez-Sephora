# Données

Le fichier de données n'est pas inclus dans ce dépôt (taille et licence).

1. Télécharger le jeu de données **Sephora Products and Skincare Reviews** sur Kaggle :
   https://www.kaggle.com/datasets/nadyinky/sephora-products-and-skincare-reviews
2. Placer le fichier `product_info.csv` dans ce dossier `data/`.
3. Lancer `python build_db.py` depuis la racine du projet.

Seul `product_info.csv` est utilisé (8 494 produits, 27 colonnes). Les fichiers d'avis ne sont pas utilisés.
